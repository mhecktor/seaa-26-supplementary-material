# SEAA 26 Supplementary Material

In this repository, you will find the code and data used for the systematic mapping study on SEAA 26. 
The code is organized into Jupyter notebooks, which are structured to follow the steps of the systematic mapping process. 
Each notebook in the folder `src/` corresponds to a specific phase of the study, such as:

1. Data collection and preparation
2. Topic clustering using BERTopic and iterations
3. Mapping and analysis of the selected papers including snowballing

The `input` contains the input files for each aforementioned phase,
while the `output` folder contains the results generated from running 
the notebooks, including intermediate and final datasets, as well as visualizations.

The document "snowballing_process.xlsx" in the `output` folder provides a detailed account 
of the snowballing process, including the papers selected and removed at each iteration, 
along with their respective reasons.
